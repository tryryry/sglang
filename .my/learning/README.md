## 组织方式说明

每个阶段一个文件，每个文件内按"任务块"组织（不强绑定到某一天）。
用 checkbox 追踪进度，随时可以调整顺序或跳过。

## 建议节奏

- 每个任务块预估 1-3 小时
- 每天完成 2-4 个任务块
- 遇到不懂的先标记 ❓，不要卡太久
- 每个阶段末尾有"自检问题"，能回答就说明掌握了
